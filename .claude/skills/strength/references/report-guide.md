# 材料レポート（HTML）の作り方

材料メモ（`作文ざいりょうメモ.md`）の中身を、本人が見てひと目で分かる・印刷できる HTML にまとめる。

- 出力先：作業ディレクトリ直下の `作文ざいりょうレポート.html`（すでにあれば上書きしてよい。正本は材料メモの方）
- テンプレート：[report-template.html](report-template.html)

## いつ作るか

1. **フェーズ7の確認が終わったとき**（材料A〜Eがそろい、本人がメモに納得したあと）に必ず作る
2. フェーズ7のあとで材料メモを直したら、作り直す
3. とちゅうで本人・おうちの人に「レポートにして」と言われたら、その時点のメモで作ってよい（まだの項目は「（まだ）」で出す）

## いちばん大事なルール

**レポートは材料メモの「見た目を変えたもの」であって、新しい文章ではない。**

- 中身は材料メモにある言葉**だけ**。メモにない言葉・説明・まとめ・感想・アドバイスを足さない
- 本人の言葉は「」付きのまま、**一字も直さない**（言いまわし・ひらがな／漢字・語尾も直さない）
- 「（まとめ）」と付いた項目は、`<span class="matome">（まとめ）</span>` を付けたまま出す
- 見出し・ラベル（「えらんだ経験」「まわりの反応」など）はテンプレートのものを使う。こちらで新しい見出しを作らない
- 作文の文・書き出し・段落の順番を示すもの（「この順に書こう」など）は入れない

## 手順

1. 材料メモを Read で読む
2. テンプレートを Read で読む
3. `{{…}}` をメモの中身に置きかえて、`作文ざいりょうレポート.html` に Write する
   - 一本の糸（ページ上部の ①〜④）：メモの該当項目から**本人の言葉の一部をそのままぬき出す**（例：えらんだ経験の「」の中身を短く）。短くするときも、言葉を言いかえたり足したりしない。ぬき出すと意味が変わりそうなら、「」全体をそのまま入れる
   - ③ はまわりの反応から1つ。反応がまだなら、むずかしかったことを入れ、ラベルはそのままでよい
   - `<!-- くりかえし -->` の行は項目の数だけ複製する
   - まだの項目：`<span class="missing">（まだ）</span>`
   - 「自分の言葉でつなげると」「まだのところ」がメモに無ければ、その section / div ごと消す
   - `<` `>` `&` は `&lt;` `&gt;` `&amp;` にする
   - テンプレート冒頭の使い方コメントは消してよい
4. 自己チェック（下）をしてから、本人に伝える：
   > 「材料を1まいのページにまとめたよ。『作文ざいりょうレポート.html』をひらくと見られるよ。印刷もできるよ。中身は、ぜんぶあなたが話した言葉だよ」
5. 材料メモの「つづきのための しるし」の「レポート」を「作った YYYY-MM-DD」に更新して保存する
6. Windows から開く場所を伝えるときは、`wslpath -w 作文ざいりょうレポート.html` で Windows 形式のパスに変換して見せる

## 自己チェック

- [ ] `{{` が残っていない（`grep -c '{{' 作文ざいりょうレポート.html` が 0）
- [ ] メモにない言葉がレポートに入っていない（ラベル・見出し以外の本文は、すべてメモにある）
- [ ] 本人の言葉を直していない
- [ ] 作文の文案・書く順番の指示が入っていない
