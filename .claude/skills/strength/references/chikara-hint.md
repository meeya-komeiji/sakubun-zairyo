# 力の言葉ヒント

**使い方（必ず守る）**
- フェーズ5で、本人が2回続けて「わからない」と言ったときだけ使う
- 全部を見せない。本人の**行動に関係ありそうなもの**を2〜4個だけ選んで出す
- 「どれもちがったら、ほかの言い方で教えて」を必ず添える
- 選んだら、そのまま採用しない。「それって、あなたの言葉で言うとどんな感じ？」「その力が出ていたのはどの場面？」と聞いて、本人の言葉に言い直してもらう
- 最後に「その力に、あなただけの名前をつけるとしたら？」と聞く

左の「こんな行動をしていたら」を手がかりに、右の言葉からヒントを選ぶ。

| こんな行動をしていたら | 力の言葉（ヒント） |
|---|---|
| こまっている人に最初に気づいた | 気づく力／よく見ている力 |
| 言われなくても動いた | 自分から動く力／ほっとけない力 |
| 相手の気持ちを考えて行動した | 相手の気持ちを想像する力 |
| 話をじっくり聞いた | 聞く力 |
| わかりやすく教えた・説明した | 伝える力／教える力 |
| けんかの間に入った・意見をまとめた | まとめる力／つなぐ力 |
| みんなの前に立った・声をかけた | 勇気／一歩ふみ出す力 |
| 何回も続けた・あきらめなかった | ねばる力／続ける力 |
| やり方を工夫した・アイデアを出した | 工夫する力／考える力 |
| みんなを明るくした・笑わせた | 元気にする力／場を明るくする力 |
| 小さい子や弱い立場の人を守った | 守る力／支える力 |
| 約束や役割を最後までやった | 責任感／やりとげる力 |
| 自分の得意なことで手伝った | 〇〇（得意なこと）を人のために使う力 |
| 落ちついて行動した | 落ちつく力／冷静さ |

## 抽象的な言葉を具体にする質問
本人が「やさしい」「がんばる」「明るい」など広い言葉を出したとき：
- それって、どんな〇〇？
- あなたの〇〇は、ほかの人の〇〇とどこがちがう？
- その〇〇が出るのは、どんなとき？
- その〇〇がなかったら、そのときどうなってたと思う？
