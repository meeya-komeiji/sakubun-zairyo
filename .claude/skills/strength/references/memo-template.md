# 材料メモのフォーマット

保存先：作業ディレクトリ直下の `作文ざいりょうメモ.md`

書き方のルール：
- 本人の言葉は「」でそのまま書く（きれいに直さない）
- こちらのまとめを書くときは「（まとめ）」と付け、本人に確認してから残す
- 箇条書きの材料だけ。作文の文章にしない
- まだ話していない項目は「（まだ）」のままにする
- 本人の答えをもらうたびに、次の質問の前に保存する。そのたびに「つづきのための しるし」も更新する（新しいチャットはここから再開する）
- 「ネタにしないことにした話」には中身を書かない。「あり」とだけ書く

---

```markdown
# 作文ざいりょうメモ

## つづきのための しるし
- よび方：〇〇
- さいごに話した日：YYYY-MM-DD（N回目）
- いまやっているところ：フェーズ3「経験をくわしく思い出す」
- つぎに聞くこと：「そのとき、あなたは何をした？」（→ 3. 自分がしたこと）
- すんだフェーズ：✅0 ✅1 ✅2 ⬜3 ⬜4 ⬜5 ⬜6 ⬜7
- ネタにしないことにした話：なし
- レポート：まだ（作ったら「作った YYYY-MM-DD」）

> フェーズの名前：0 はじめに／1 経験のネタ出し／2 経験を1つえらぶ／3 経験をくわしく思い出す／4 まわりの反応とむずかしかったこと／5 自分の力を見つける／6 大人になってリーダーとしてやりたいこと／7 メモの完成と確認・レポート

## 作文で書く4つのこと
1. 自分の力を人のために使った（使いたいと思った）経験
2. そのときのまわりの人の反応
3. むずかしかったこと
4. 大人になって、リーダーとしてやってみたいこと
```
