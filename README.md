# 作文の「ざいりょう」あつめ 📝

作文を書く前に、**書くことのたね（ざいりょう）**を、AI といっしょにあつめるための場所です。

> 👨‍👩‍👧 **おうちの人へ：はじめての方は、まず [はじめての じゅんび](#はじめての-じゅんびおうちの人と-いっしょに) から読んでください。**
> GitHub（ギットハブ）を さわったことが なくても、だいじょうぶなように 書いてあります。

---

## これって、なにをするの？

テストの作文のテーマは、こんなお話です。

> じぶんの力を、だれかのためにつかったこと（または、つかいたいと思ったこと）。
> そのときの、まわりの人のようす。
> むずかしかったこと。
> 大人になって、リーダーとしてやってみたいこと。

「いきなり書いて」と言われても、むずかしいよね。
だから AI が、**しつもんを1つずつ**してくれます。
あなたは、思ったことを、そのまま答えるだけで大丈夫。

- ✅ 正しい答えは、ありません
- ✅ 「わからない」も、OK です
- ✅ 小さなできごとで、いいんです（小さいほうが、くわしく書けます）
- ✅ つかれたら、とちゅうでやめても大丈夫。つづきは、また今度できます

> **作文の文は、AI は書きません。** 作文は、あなたが自分の言葉で書くものだからです。
> AI のしごとは、あなたの中にある「書きたいこと」を見つけるお手伝いです。

## はじめての じゅんび（おうちの人と いっしょに）

> ここは、**おうちの人が いっしょに やるところ**です。
> いちど じゅんびが できたら、つぎからは「[どうやって はじめるの？](#どうやってはじめるの)」だけで 大丈夫。

じゅんびは 4つの ステップです。

| ステップ | やること | かかる時間（めやす） |
|---|---|---|
| 0 | ひつような ものを たしかめる | 1分 |
| 1 | この ページから、フォルダを ダウンロードする | 5分 |
| 2 | Claude Code を 入れる | 10分 |
| 3 | はじめての ときだけ 聞かれることに 答える | 5分 |

### ステップ0：ひつような もの

| ひつような もの | くわしく |
|---|---|
| 💻 パソコン | Windows 10 いじょう、または Mac（macOS 13 いじょう） |
| 🌐 インターネット | つながっていれば OK |
| 🔑 Claude の アカウント | **有料プラン（Pro など）が ひつよう**です。無料プランでは Claude Code は つかえません |
| 🐙 GitHub の アカウント | **いりません。** ダウンロードだけなら、登録なしで できます |

### ステップ1：この ページから フォルダを ダウンロードする

#### GitHub（ギットハブ）って なに？

いま 見ている この ページが **GitHub** です。
プログラムや ファイルを、インターネット上で 公開・共有するための サービスです。

ページの 上のほうに、ファイルや フォルダの 名前が ならんでいますね。
これが このしくみの 中身です。**1つずつ ひらいたり、さわったり しなくて 大丈夫。**
ひつようなのは、**ぜんぶ まとめて ダウンロードする** ことだけです。

#### ダウンロードの しかた

1. この ページの 上のほうにある、**緑色の「<> Code」ボタン** を おします
2. 出てきた メニューの いちばん 下にある **「Download ZIP」** を おします
3. `sakubun-zairyo-main.zip` という ファイルが ダウンロードされます（ふつうは「ダウンロード」フォルダに 入ります）

> 💡 「Fork」「Star」「Sign in」などの ボタンも ありますが、**つかいません**。おさなくて 大丈夫です。

#### ZIP（ジップ）を ひらく（「展開（てんかい）」する）

ZIP は、たくさんの ファイルを 1つに まとめて ちいさくした ものです。
このままでは つかえないので、**中身を とりだします**。

- **Windows** の人：ダウンロードした `sakubun-zairyo-main.zip` を **右クリック** →「**すべて展開**」→「**展開**」
- **Mac** の人：ダウンロードした `sakubun-zairyo-main.zip` を **ダブルクリック**（自動で とりだされます）

`sakubun-zairyo-main` という **フォルダ** が できたら 成功です。

> ⚠️ **Windows の人は ちゅうい！** ZIP ファイルを ダブルクリックすると、中が 見えますが、それは まだ「とりだして いない」状態です。
> そのまま つかうと うまく うごきません。かならず「**すべて展開**」を してください。

#### フォルダを すきな場所に おく

1. できた フォルダの 名前を `sakubun-zairyo-main` から **`sakubun-zairyo`** に かえます（この 説明と 同じ 名前に なって、わかりやすくなります）
2. その フォルダを、すきな 場所に うごかします（たとえば「ドキュメント」の中）

> ⚠️ **だいじ！** フォルダの中には `.claude` という フォルダが あります。
> この中に、AI が しつもんを する ための ルールが 入っています。
>
> - **Mac** では、`.` で はじまる フォルダは **ふだん 見えません**（でも、ちゃんと 入っています）
> - フォルダを うごかす・コピーする ときは、中の ファイルを えらんで うごかさず、**`sakubun-zairyo` フォルダ まるごと** うごかしてね

### ステップ2：Claude Code を 入れる

やり方は 2つ。**はじめての人は A が かんたん**です。

#### A. アプリで つかう（おすすめ・黒い画面を つかわない）

1. Claude の 公式サイトから **「Claude」の デスクトップアプリ** を ダウンロードして、入れます
2. アプリを ひらいて、Claude の アカウントで ログインします
3. 上のほうの **「Code」タブ** を おします
4. 入力らんの 下にある **フォルダを えらぶ ボタン** を おして、`sakubun-zairyo` フォルダを えらびます

くわしくは 公式の 説明ページ（英語）：https://code.claude.com/docs/en/desktop

#### B. ターミナル（黒い画面）で つかう

**① 入れる**

- **Windows** の人：スタートメニューで「PowerShell」を さがして ひらき、つぎの 1行を はりつけて Enter

  ```powershell
  irm https://claude.ai/install.ps1 | iex
  ```

- **Mac** の人：「ターミナル」アプリを ひらき、つぎの 1行を はりつけて Enter

  ```bash
  curl -fsSL https://claude.ai/install.sh | bash
  ```

おわったら、ターミナルを いちど とじて、ひらきなおします。
`claude --version` と 入力して、`2.1.〇〇 (Claude Code)` のように 出たら 成功です 🎉

**② `sakubun-zairyo` フォルダで ひらく**

- **Windows**：エクスプローラーで `sakubun-zairyo` フォルダを ひらき、上の **アドレスバー** に `powershell` と 入力して Enter → そのフォルダで 黒い画面が ひらきます
- **Mac**：ターミナルで `cd ` （cd と スペース）と 入力してから、`sakubun-zairyo` フォルダを ターミナルの 画面に **ドラッグ** して、Enter

**③ Claude Code を うごかす**

```
claude
```

と 入力して Enter。

### ステップ3：はじめての ときだけ 聞かれること

- **ログイン**：ブラウザが ひらくので、Claude の アカウントで ログインします
- **「このフォルダを 信頼（しんらい）しますか？」**：**「はい」** を えらびます
  - これを えらぶと、AI が メモ（`作文ざいりょうメモ.md`）と レポートを、**いちいち 聞かずに 書けるように** なります（それ いがいの ファイルは、ちゃんと 聞いてから 書きます）

これで じゅんび かんりょう！ 🎉
つぎからは、GitHub の ページを ひらく ひつようは ありません。

## とちゅうで やめても 大丈夫？

**大丈夫！** 🙆

あなたが答えるたびに、AI がすぐに メモ に書いておきます。
「つぎは どこから やるか」も、メモに書いてあります。

だから、こんなときでも、つづきから できます。

- つかれて、とちゅうで やめたとき
- パソコンを とじちゃったとき
- 何日か あいだが あいたとき

### つづきを やるときは

1. このフォルダで、Claude Code を ひらきます（新しい チャットで OK）
2. こう 入力します

   ```
   /strength
   ```

   （「つづきやりたい」と書いても、はじまります）

3. AI が メモを読んで、「前回は ここまで 話したね」と おしえてくれます
4. あとは、また しつもんに 答えるだけ！

> ⚠️ メモ（`作文ざいりょうメモ.md`）を けしたり、うごかしたり しないでね。
> つづきは、このメモを 見て はじめるからです。

## できあがるもの

あなたの パソコンの `sakubun-zairyo` フォルダに、2つのファイルができます。

### 📄 `作文ざいりょうメモ.md`
話したことの メモ です。答えるたびに、どんどん ふえていきます。
とちゅうで やめても、次はここから つづきが できます。

### 🌈 `作文ざいりょうレポート.html`
ざいりょうが ぜんぶ あつまったら できる、**見やすいページ**です。
ダブルクリックすると、ブラウザでひらけます。いんさつも できます。

中には、**あなたが話した言葉だけ**が入っています。
「経験 → じぶんの力 → まわりのようす → 未来」が、ひと目で つながって見えます。

作文を書くときは、このレポートを見ながら、**じぶんの言葉で**書いてね。

> 🔒 この 2つの ファイルは、**あなたの パソコンの 中だけ** に できます。
> GitHub に アップロードされたり、ほかの人に 見られたり することは ありません。

## こまったときは

| こんなとき | やってみること |
|---|---|
| 緑の「<> Code」ボタンが 見つからない | GitHub の ページの いちばん 上（ファイルの 一覧の すぐ 上）を 見てください。スマホでは 見つけにくいので、パソコンで ひらいてください |
| ダウンロードした ファイルが どこに あるか わからない | **Windows**：ブラウザで `Ctrl`＋`J` を おすと、ダウンロードした ファイルの 一覧が 出ます。**Mac**：Finder の 左にある「ダウンロード」を 見てください |
| `.claude` フォルダが 見つからない（Mac） | Finder で `⌘`＋`Shift`＋`.`（ピリオド）を おすと、見えない フォルダも 見えるように なります（もう一度 おすと もとに もどります） |
| `claude` と 入力したら「見つかりません」と出る | ターミナルを とじて、ひらきなおす。それでも だめなら、もういちど「入れる」の 1行を ためす |
| `/strength` が 出てこない・はじまらない | ①ZIP を「展開」してから つかって いるか ②`sakubun-zairyo` フォルダで ひらいて いるか（その 中の フォルダや、1つ上の フォルダでは ないか） ③`.claude` フォルダも いっしょに うごかせて いるか を たしかめる |
| 答える たびに「ファイルを 書いていい？」と 聞かれる | 「このフォルダを 信頼しますか？」で「はい」を えらんだか たしかめる。聞かれたら「はい」で OK（メモに 書く ためです） |
| 「つづき」に ならず、さいしょから はじまる | `作文ざいりょうメモ.md` が `sakubun-zairyo` フォルダの 中に あるか たしかめる |
| ログインが できない | Claude の 有料プランに 入って いるか たしかめる |

## おうちの人へ

- このしくみは「聞き役」に しぼっています。AI は作文の本文・書き出し・例文を出さず、添削もしません。テストの注意書き「自分の頭で考えたことを自分の言葉で書く」を守るためです
- メモとレポートには、お子さんの言葉が「」でそのまま残ります（AI がきれいな言葉に直すことはありません）
- メモとレポートは、ダウンロードした フォルダの 中（お使いの パソコン）に だけ 保存されます。GitHub に 送られることは ありません。会話の 内容そのものは、ふつうに Claude を つかう ときと 同じように Anthropic 社の サービスで 処理されます
- いじめ・家族のこと・病気など、つらそうな話が出たときは、AI は深く聞かず「おうちの人や先生にも聞いてもらおう」と伝えて、別の話題にうつります。ネタにするかどうかは、ご家庭で相談してください
- 1回 20〜30分くらいが目安です。つかれていそうなら、AI のほうから休けいを すすめます
